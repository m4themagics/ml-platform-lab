# Architecture decision records

One file per decision that changes a system boundary, failure behaviour, cost or security
posture. Use `NNNN-short-title.md` with:

```text
Status:
Context:
Decision:
Alternatives considered:
Failure and rollback implications:
Cost and security implications:
Evidence required:
Revisit trigger:
```

The first planned ADRs cover local cluster choice, model packaging strategy, rollout
controller and the minimal AWS database/network topology. They are written when the decision
is made, not pre-filled with an answer in phase 0.
